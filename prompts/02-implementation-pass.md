# Промпт: реализация текущей задачи

Реализуй только текущую Txxx по утверждённому плану.

- Сначала создай/уточни минимальные тесты, доказывающие критерии.
- Затем добавь минимальный production-код.
- Сохраняй границы `simulation/game/ui/content`.
- Не добавляй зависимость, если задача решается прозрачной небольшой функцией.
- Не создавай универсальную абстракцию для одного применения.
- Запусти целевые проверки через Docker.
- Покажи краткий итог и не переходи к следующей задаче.
