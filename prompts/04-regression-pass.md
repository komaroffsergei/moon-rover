# Промпт: регрессия

Запусти доступный полный quality gate через Docker. Не меняй код до получения фактической ошибки.

При падении:

1. воспроизведи минимально;
2. укажи нарушенное требование;
3. исправь первопричину минимальным diff;
4. добавь regression test;
5. повтори сначала упавшую проверку, затем весь gate.

Не обновляй зависимости и не рефактори соседний код как способ «починить всё сразу».
