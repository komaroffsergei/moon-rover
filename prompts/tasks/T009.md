# Готовый промпт T009

Выполни `T009` — **Игровая карта Phaser**.

## Цель

Отобразить валидированную Tiled-карту, объекты и ручной маршрут, не перенося правила в Phaser.

## Обязательный контекст

- `AGENTS.md`
- `.agents/skills/moon-courier-sdd/SKILL.md`
- `tasks/T009-phaser-map.md`
- `features/F009-phaser-map.md`
- `specs/technical/05-map-tiled.md`
- `specs/ui/02-main-layout.md`
- `specs/ui/03-interaction-states.md`
- `contracts/tiled-layer-contract.md`
- `references/README.md`

## Порядок

1. Проведи краткий spec-audit по `prompts/01-spec-audit.md`.
2. Составь план максимум из 8 пунктов по `PLANS.md`.
3. Реализуй минимальный законченный срез, не выходя за `Не входит`.
4. Выполни три прохода `quality/THREE_PASS_WORKFLOW.md`.
5. Создай `reports/T009.md`.
6. Остановись после этой задачи.

Все команды и проверки выполняй через Docker Compose. Не считай работу завершённой без фактических результатов команд.
