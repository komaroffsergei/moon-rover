# Moon Courier SDD workflow

1. Прочитать корневой `AGENTS.md`.
2. Открыть ровно одну `tasks/Txxx-*.md`.
3. Загрузить только документы из её раздела «Контекст задачи».
4. Сопоставить task, feature spec и контракты.
5. Составить план максимум из 8 пунктов.
6. Реализовать минимальный законченный срез.
7. Выполнить `quality/THREE_PASS_WORKFLOW.md`.
8. Создать отчёт задачи.

## Экономия контекста

- Не читать весь каталог specs и все изображения.
- Не повторять спецификацию в отчёте: ссылаться на требование и показывать код/тест.
- Перед следующей задачей читать только предыдущий отчёт и новый контекст.

## Пробелы

Сначала проверить `specs/product/03-decisions.md` и `04-assumptions.md`. Если ответа нет, выбрать минимальное поведение, записать допущение, но не редактировать нормативный документ без отдельной задачи.

## Контроль

Игровую логику проверять с фиксированным seed и clock; UI — Playwright; карты — контент-валидатором; новую зависимость — по необходимости, лицензии и размеру.
