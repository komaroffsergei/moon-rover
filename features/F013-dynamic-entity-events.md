# F013. Динамические события сущностей

## Цель

Повысить читаемость и темп диспетчерской карты без переноса игровых правил в
UI и без добавления ручного управления.

## Требования

### F013-R1. Реплики на карте

- Центр, курьер или ремонтный ровер при относящемся к нему событии показывает
  над моделью короткую comic-style реплику от первого лица.
- Реплика дополняет рацию: журнал сохраняет полную хронологию.
- Текст локализован контентом; renderer не сочиняет доменные сообщения.

### F013-R2. Точная автоматическая разгрузка

- При конечном прибытии в центр курьер отдаёт только ресурс и количество,
  необходимые для восстановления центра.
- Ненужные ресурсы и избыток остаются в cargo ровера.
- Pass-through клетки центра не запускают разгрузку.

### F013-R3. Динамическое размещение

- При создании новой смены база и центры размещаются seed-детерминированно.
- Все facility cells различны, проходимы, достижимы и воспроизводимы одинаковым
  seed.
- Random placement не меняет Tiled-рельеф, hazards и obstacles.

### F013-R4. Кратчайший поворот

- При назначении близкого нового направления ровер вращается по кратчайшей
  угловой дуге.
- Reroute сохраняет текущую позицию и не создаёт разворот на 180° из-за перехода
  через границу `-π/π`.

## Приёмка

Требования доказаны simulation/content/game tests и реальным Playwright
сценарием; console/network clean, layout пригоден на 1280×720.
