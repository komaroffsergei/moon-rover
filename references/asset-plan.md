# План ассетов

## MVP

| Элемент | Формат | Количество | Источник/подход |
|---|---|---:|---|
| Фон карты | WebP | 4 | crop из разрешённого лунного источника или собственный paint-over |
| Логический tileset | PNG/WebP atlas | 1 | собственные простые паттерны 32/48 px |
| Ровер courier | sprite sheet WebP | 1 | 4 направления × 2–4 кадра |
| Repair rover | sprite sheet WebP | 1 | визуально отличим |
| База/центры | WebP | 4–6 | статические + warning overlay |
| События | small sprite/VFX | 3 | буря, удар, кратер |
| UI | SVG/PNG | выборочно | собственные SVG или Kenney CC0 |
| Звук | OGG + MP3 fallback | 6–10 | Kenney CC0 или собственный |

## Правила импорта

- Импортировать только реально используемые файлы.
- Сохранять исходную лицензию рядом в `licenses/`.
- Приводить имена к kebab-case.
- Удалять metadata/лишние alpha margins.
- Не upscale raster.
- Фоны грузить по выбранному уровню, не все четыре сразу.
- UI icons предпочтительно inline SVG через локальные компоненты, без icon framework.

## Переключение темы

Theme JSON меняет цвета grid/hazard/route/panels и пути к фону/atlas. Геометрия карты и значения риска остаются в level content. Смена темы не должна менять Tiled-файл и игровую логику.
