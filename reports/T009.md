**Цель:** отобразить один согласованный validated Tiled runtime bundle в Phaser,
проецировать snapshot/route state и переводить реальные pointer intents в
ручной маршрут без переноса simulation-правил в сцену.

До реализации обнаружено, что `level-02-shackleton.json` ссылался на
отсутствующий map, единственный `minimal-map.tmj` имел несовместимые IDs, а все
asset paths вели в отсутствующий `public/`. Минимальный законченный срез создаёт
один Shackleton bundle, согласованный с level meta, и реальные локальные assets;
T011 расширит его до четырёх карт, но T009 не использует procedural fallback.

`src/game` получает узкий `MapGameController` port с serializable view state и
intents. Его реализация находится в `src/app`, где разрешены simulation/content
imports; Phaser не вычисляет adjacency, walkability, risk, battery или forecast.
Выбор rover и клеток выполняется кликами. Triangle control сначала явно запускает
смену из BRIEFING, а при непустом draft явно confirm+dispatch route. Повторный
клик по предыдущей клетке/правый клик делает undo, Escape очищает draft; T010
заменит эту map-native презентацию панельными действиями.

Camera policy: `Phaser.Scale.RESIZE`; world bounds равны map pixel bounds;
initial/min zoom — contain-fit, max zoom `3`; wheel zoom привязан к pointer;
drag начинается после 6 px и не считается cell click; resize сохраняет world
center и затем clamp. Cell policy — `floor(world / 64)` с half-open bounds
`[0,width×64) × [0,height×64)`, outside возвращает `null`.

Embedded tileset дополнительно проверяется как целостный atlas: `tilecount`,
`columns`, tile size, `margin` и `spacing` обязаны точно объяснять
`imagewidth/imageheight`. Это не позволяет Phaser молча перейти с заявленных
64×64 кадров на вычисленные 66×66. Controller выводит полный набор domain-goals:
base, center, rover и `RESCUE_ADJACENT` для cardinal neighbor.

### Риски

- Camera transform и CSS resize могут разъединить pointer и grid — pure math и
  real resize click закрепляются отдельно.
- Scene может незаметно продублировать routing rules — candidates/draft/forecast
  разрешены только через injected controller.
- Пересоздание Phaser objects каждый frame даст leaks/мигание — renderer keyed
  по entity ID и reconciles lifecycle.
- Canvas assertions без rendered evidence пропустят пустые/missing textures —
  Playwright ждёт semantic ready marker, сеть/console и screenshots проверяются.

## Результат

Реализован законченный map-only vertical slice для `shackleton-rift`: Phaser
загружает валидированный raw TMJ через Tiled parser, подключает embedded tileset
и Image Layer, рисует крупную hazard-зону, препятствия, базу, три центра и три
ровера. Реальные canvas-клики запускают смену, выбирают ровер, строят cardinal
route draft, показывают candidates/forecast, отправляют маршрут и наблюдают
интерполированное движение из snapshot.

Simulation остаётся владельцем правил и state. `src/game` получает только
`PhaserMapSource` и `MapGameController` port; app-controller использует public
routing helpers и typed engine commands. Camera поддерживает bounded pan,
pointer-anchored zoom и resize с сохранением world center/selection. Runtime не
использует географические координаты, physics, MapLibre или procedural assets.

## Три прохода

1. **Спецификация.** Requirement matrix сопоставлена тестам. Исправлены
   отсутствующий coherent bundle/assets, permissive transformed layers, ручной
   DTO-render вместо Phaser Tiled parser, исчезавший после dispatch active route,
   одна вместо трёх center bars и слабое evidence движения.
2. **Простота и границы.** Endpoint→goal вынесен из Phaser в app-controller;
   полный goal inference включает соседнюю rescue-клетку, а
   adjacency/walkability/forecast остаются public simulation helpers. Удалён
   неиспользуемый object atlas, diagnostics включаются только `?e2e=1` и
   throttled, shutdown снимает global listeners. Right-click больше не активирует
   объект/control одновременно с undo; forecast закреплён в screen-space и не
   заслоняет map-object.
3. **Регрессия.** Fresh Docker verify прошёл format/lint/typecheck, 274 unit/
   integration tests, 6 content documents и production build. Один и тот же
   Playwright-сценарий прошёл на Vite и nginx: start → select → 8 clicks →
   dispatch → rendered movement → arrival → zoom/pan → mobile resize → visible
   candidate click. Финальный diff/CODEMAP/report сверены.

## Допущения

- T009 реализует один coherent Shackleton vertical slice; четыре законченных
  уровня и финальный balance принадлежат T011.
- Contain-fit сохраняет видимость всей карты; боковые поля являются будущими
  областями React layout T010, а не растягиванием logical grid.

## Зависимости и лицензии

Новых npm-зависимостей нет. Lunar background, tile atlas, base/center/rover
sprites и concept сгенерированы для проекта через ImageGen и хранятся локально;
сторонние изображения или сетевые runtime assets не используются.

## Остаточные риски

- Текущий TMJ намеренно мал (8×6) для проверяемого vertical slice; визуальное и
  balance-разнообразие четырёх production maps остаётся задачей T011.
- Vite предупреждает о Phaser-containing JS chunk 1,742.54 kB (gzip 466.87 kB);
  функциональный budget не нарушен, а code splitting/performance gate относится
  к T012.
