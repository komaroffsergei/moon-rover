# Отчёт T001

## План до кода

**Цель:** создать минимальный запускаемый каркас, в котором все команды
разработки выполняются через Docker Compose.

**Контекст:** `AGENTS.md`, `.agents/skills/moon-courier-sdd/SKILL.md`,
`tasks/T001-bootstrap.md`, `features/F001-bootstrap.md`,
`specs/technical/01-stack.md`, `specs/technical/03-project-layout.md`,
`specs/technical/13-module-boundaries.md`, `specs/technical/08-docker.md`,
`specs/technical/09-dependencies.md`.

### Spec-audit

| ID      | Наблюдаемое поведение                        | Проверка                     |
| ------- | -------------------------------------------- | ---------------------------- |
| T001-R1 | React создаёт ровно один Phaser canvas       | Playwright в dev и nginx     |
| T001-R2 | TypeScript strict и quality scripts проходят | Compose verify gate          |

Существенных конфликтов не найдено. До T002 `validate:content` подтверждает
отсутствие runtime JSON-контента. Инфраструктурный Playwright smoke не вводит
игровой E2E-flow и нужен для обязательной проверки реального экрана.

### План

1. Развернуть SDD-пакет и отметить только T001 как `in_progress`.
2. Материализовать Docker/Compose-контур и точный dependency manifest.
3. Добавить boundary, content и browser smoke-проверки.
4. Создать lockfile только внутри контейнера.
5. Реализовать минимальный React + Phaser bootstrap.
6. Обновить README/CODEMAP и пройти проверку спецификации.
7. Просмотреть diff на простоту и границы, затем выполнить полный regression.
8. Заполнить этот отчёт, завершить T001 и остановиться.

## Результат

T001 выполнена. Создан минимальный Vite + React + TypeScript strict каркас:
React владеет жизненным циклом одного экземпляра Phaser, а пустая
`BootstrapScene` создаёт единственный canvas 1280×720 без игровой логики.

Все рабочие сценарии оформлены сервисами Docker Compose: `dev`, `verify`,
`e2e` и `app`. Production image собирается multi-stage Dockerfile и содержит
только nginx, его конфигурацию и статический `dist`.

## Три прохода

### 1. Соответствие спецификации

- Для каждого критерия T001 добавлено доказательство в таблицу выше.
- Целевые format/lint/typecheck/unit/content/build проверки выполнены через
  `verify`; браузерный smoke выполнен отдельно для dev и production.
- Исправлены фактические проблемы сборочного контура: Docker deps stage начал
  копировать `pnpm-workspace.yaml`, разрешён build script только для `esbuild`,
  а Playwright использует тот же pnpm store с frozen lockfile.

### 2. Простота и границы

- Независимо просмотрены Docker-контур, React/Phaser lifecycle, browser smoke
  и ESLint matrix.
- Закрыты доказанные обходы границ через пути вида `./../…` и imports из
  `tests`; добавлены негативные fixtures.
- Проверка одного canvas сделана глобальной, из пустой scene удалён
  декоративный текст, а README получил точную nginx smoke-команду.
- Игровых правил, коэффициентов, speculative layers и зависимостей вне
  allowlist нет; изменения за пределами T001 не найдены.

### 3. Регрессия и пользовательский сценарий

- После всех исправлений повторно пройден полный `verify` gate.
- Playwright прошёл сценарий мышью на Vite и nginx; console/network/layout
  проверки зелёные, оба screenshots просмотрены.
- Runtime image проверен изнутри. Итоговые дерево файлов, README и CODEMAP
  повторно сверены с фактической реализацией.

## Допущения

- До появления первого `compose.yaml` архив был разложен на хосте как
  неизбежный bootstrap; после этого install/build/lint/test/runtime-команды
  выполнялись только через Docker Compose.
- T001 исключает полноценный E2E-flow, поэтому добавлен ровно один
  инфраструктурный browser smoke, необходимый для проверки реального canvas и
  обязательного Compose-сервиса `e2e` из F001.
- До T002 runtime JSON в `src/content` запрещён guard-скриптом; схемный
  content validator будет реализован следующей задачей, но она не начиналась.
- Пустой равномерно тёмный canvas — ожидаемый вид scene-заглушки T001, а не
  финальный UI.

Playwright package и официальный browser image используют одну версию
`1.62.1`. Ассеты не добавлялись.

## Остаточные риски

- Phaser формирует начальный JS chunk около 1.57 MB (около 418 KB gzip), из-за
  чего Vite печатает предупреждение порога 500 KB. Для T001 это не нарушает
  критерии, но вес startup bundle следует повторно оценить при работах по
  производительности.
- Browser smoke выполнен в Chromium из официального Playwright image;
  кросс-браузерное покрытие намеренно не входит в T001.
