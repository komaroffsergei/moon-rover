# Отчёт T005

## План до кода

**Цель:** реализовать ручное построение и подтверждение маршрута rover,
проверку допустимых целей и прогноз длины, времени, батареи и риска — без
автопоиска, фактического движения и Phaser input.

**Контекст:** `AGENTS.md`, `.agents/skills/moon-courier-sdd/SKILL.md`,
`tasks/T005-manual-route.md`, `features/F005-manual-route.md`,
`specs/gameplay/05-manual-routing.md`, `specs/gameplay/10-state-model.md`,
`specs/technical/06-map-validation.md`, `contracts/tiled-layer-contract.md`,
`reports/T004.md`.

| ID      | Наблюдаемое поведение                                                                  | Проверка                              |
| ------- | -------------------------------------------------------------------------------------- | ------------------------------------- |

| T005-R3 | Confirm требует хотя бы один шаг и допустимую live-цель; результат глубоко неизменяем  | confirm/goal/immutability tests       |
| T005-R4 | Назначение начинается из текущей logical cell и атомарно заменяет старый маршрут       | engine assignment/redirect tests      |
| T005-R5 | Допустимы base, center, rover cell и ортогонально соседняя rescue cell                 | endpoint matrix tests                 |
| T005-R6 | Forecast исключает origin, но учитывает повторный вход через допустимый цикл           | mixed-cost/repeated-cell tests        |
| T005-R7 | Время и батарея используют общие cell-entry functions; cargo не влияет                 | shared-cost/runtime coefficient tests |
| T005-R8 | Риск равен `1 - product(1 - effectiveCellChance)` и использует validated map data      | risk boundaries/content-adapter tests |

Выявленные пробелы закрыты минимально: effective chance обычной клетки берётся
из `balance.incidents.normalCellChance`, hazard-клетки — из связанного
`IncidentProfiles.cellChance`; hazard не блокирует клетку, obstacle блокирует.
Черновик остаётся application value и не входит в engine snapshot. Empty undo
идемпотентен. Confirm/send разрешён в RUNNING и PAUSED; IDLE/MOVING rover
считается исправным, а будущие incident statuses не вводятся заранее.

В feature есть E2E-критерий кликов по клеткам, но task явно исключает Phaser
mouse input. Поэтому T005 проверяет simulation/application API; route-click E2E
не заявляется выполненным и остаётся до задачи, вводящей игровой input.

- Forecast и будущее движение могут считать стоимость по-разному — обе метрики

## Результат

Реализован ручной маршрут как чистый application/simulation API. Черновик
добавляет только явно выбранную соседнюю walkable-клетку, поддерживает explicit
undo/clear и не запускает поиск. Confirm проверяет live-цель и создаёт глубоко
неизменяемый value object. Команда engine начинает маршрут из текущей logical
cell исправного rover и атомарно заменяет прежнее назначение.

Runtime routing grid формируется из уже валидированных terrain, obstacles и
hazards: сохраняет movement cost, накладывает блокирующее препятствие и связывает
hazard с точным incident profile. Forecast считает длину, игровые минуты,
стоимость/остаток батареи и совокупный риск по каждой входной клетке. Фактическое
движение и Phaser input не добавлялись.

## Три прохода

1. **Спецификация:** независимый review связал критерии с тестами и обнаружил
   row-index aliasing в публичном forecast для forged out-of-bounds draft.
   Добавлена обязательная route validation и regression; уточнён конфликт
   feature E2E с task scope.
2. **Простота и границы:** skill `simplify` и независимый review подтвердили
   разделение domain/content/simulation и отсутствие balance в коде. Удалены два
   неиспользуемых type-alias; новых слоёв, зависимостей и fallback paths нет.
3. **Регрессия:** полный immutable-image gate, content examples, production
   build и реальный Playwright smoke прошли; CODEMAP и итоговый scope сверены.

## Допущения

- `effectiveCellChance` обычной клетки — validated
  `balance.incidents.normalCellChance`; hazard-клетки — `cellChance` связанного
  incident profile. Hazard не блокирует, obstacle блокирует.
- Command `steps` не содержит origin: engine захватывает текущую logical cell в
  момент отправки. Empty undo идемпотентен.
- Назначение разрешено в RUNNING/PAUSED. На этапе T005 существующие
  IDLE/MOVING statuses считаются исправными; будущие incident statuses не
  вводятся заранее.
- Недостаток батареи отображается прогнозом (`batteryRemaining = 0`), но не
  отклоняет ручной маршрут.

## Остаточные риски

`features/F005-manual-route.md` требует E2E кликов по клеткам, тогда как
`tasks/T005-manual-route.md` явно исключает Phaser mouse input. T005 поэтому
доказывает routing через unit/integration API и выполняет общий browser smoke,
но не заявляет route-click E2E; он остаётся до scoped задачи игрового ввода.

Фактическое движение и списание батареи намеренно входят в T006. Общие
cell-entry cost functions уже экспортированы и должны использоваться там.
Production build сохраняет известное предупреждение Vite о Phaser chunk
1.566 MB (gzip 417.81 kB), без ошибки gate.
