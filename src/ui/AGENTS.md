# Правила `src/ui`

- React показывает snapshot и отправляет команды.
- Нельзя изменять доменные объекты и хранить копию симуляции.
- Plain CSS; без UI framework.
- Компоненты маленькие по реальной ответственности, а не по количеству div.
- Доступность и desktop 1280×720 являются критериями, не украшением.
