# Правила `src/domain`

- Только стабильные сериализуемые контракты: ID, команды, события, snapshot и DTO runtime-контента.
- Не импортировать React, Phaser, Zustand, DOM или файлы чтения JSON.
- Не помещать сюда алгоритмы «на будущее»; поведение принадлежит `simulation`.
- Изменение публичного контракта требует обновления потребителей и тестов в той же задаче.
