# Правила `src/game`

- Phaser отвечает только за отрисовку, камеру, pointer input и визуальные эффекты.
- Нельзя рассчитывать расход ресурсов, исход события, батарею и состояние центра.
- Клик преобразуется в типизированную команду SimulationEngine.
- Визуальное состояние всегда восстанавливается из snapshot.
