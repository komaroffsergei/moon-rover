# Правила `src/content`

- Карты, баланс, события, тексты рации и темы — отдельные валидируемые данные.
- Ни один JSON не используется до Zod/content validation.
- Tiled tileset должен быть embedded; внешний `source` запрещён.
- Изменение коэффициента не требует изменения simulation-кода.
- Ассеты локальны и имеют понятную лицензию.
