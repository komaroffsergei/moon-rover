# Производительность

Цель: 60 FPS на обычном desktop GPU, корректная симуляция при 30 FPS/свёрнутой вкладке.

Ограничения MVP:

- карта до 40×24 клеток;
- до 8 роверов и 6 центров;
- React panels вне canvas, без DOM markers поверх карты;
- Phaser objects обновляются, не пересоздаются на каждый snapshot;
- comic-style реплики используют фиксированный пул из трёх Phaser containers и
  ограниченную очередь вместо создания объектов на каждое событие;
- store использует селекторы;
- UI snapshot публикуется не чаще 10 раз/с, движение интерполируется визуально;
- ассеты выбранного уровня локальные и предзагружаются.

Проверки: ускоренная 480-секундная симуляция, E2E без console errors, ручной profiler только после фактической проблемы.
