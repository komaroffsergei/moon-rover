# Тайлы и ассеты

## Поверхность

Для каждого из пяти уровней:

1. один цельный лунный фон WebP 2048×1024/1536;
2. маленький прозрачный logical tileset `normal/rough/blocked`;
3. маленький overlay atlas краёв/штриховки hazard;
4. компактные спрайты базы, центров и роверов.

Это легче и естественнее повторяющегося тяжёлого tileset, но сохраняет редактируемую геометрию Tiled.

## Бесплатные источники

- NASA SVS CGI Moon Kit — исходники лунной поверхности; брать crop, уменьшать, хранить локально.
- Kenney UI Pack Sci-Fi — CC0, выборочные панели/кнопки.
- Kenney Interface Sounds — CC0, 6–10 коротких звуков.
- Game-icons.net — SVG, CC BY 3.0, обязательна атрибуция.
- OpenGameArt Moon Surface 2D — очень лёгкий CC BY placeholder; не основной финальный стиль.
- OpenGameArt Space Isometric Pixel Art — лёгкий CC0, но не смешивать с ортогональной картой без отдельного решения об арт-направлении.

## Что рисовать Phaser Graphics

Цельные контуры опасностей, blocked-рельеф, плавную линию подтверждённого
маршрута, waypoint цели и полосы ресурсов. Логическая сетка, соседние клетки и
кандидаты маршрута не рисуются. Это несколько доменных примитивов, а не
самописный графический движок.

## Бюджет

- initial load с первой картой до 6 MB compressed;
- фон карты до 600 KB WebP;
- UI atlas до 512 KB;
- object atlas до 1 MB;
- звук до 1 MB;
- текстура не больше 4096 px;
- runtime CDN запрещён.

## Решение по tileset

Не искать один «магический» пакет, который определит архитектуру карты. Для MVP создать один логический atlas максимум из 8–16 элементов: normal/rough/blocked, 2–4 hazard patterns и служебные маркеры. Это технический ассет, а не самостоятельная художественная система; фон даёт NASA crop/WebP, объекты — отдельные sprites.
