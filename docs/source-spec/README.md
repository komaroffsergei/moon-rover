# Исходные требования Moon Courier Crisis

Здесь опубликован исходный SDD-пакет, по которому начиналась разработка игры,
и отделён от актуальных нормативных документов проекта.

- [SDD v1.0.0 от 13 августа 2026 года](v1.0.0/README.md) — архивный снимок
  первоначальных требований и процесса разработки.
- [Актуальные спецификации](../../specs/) — действующая версия требований после
  feature F013–F016 и последующей продуктовой доводки.
- [Исходные визуальные референсы](../../references/README.md) — изображения из
  первоначального пакета; они уже находились в репозитории и не дублируются.

Разделение важно для трассируемости: актуальные `specs/`, `features/` и
`contracts/` развивались вместе с игрой и больше не являются побайтовой копией
первого пакета.
