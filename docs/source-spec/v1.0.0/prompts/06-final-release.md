# Промпт: финальная проверка T012

Проведи выпускной аудит без добавления новых возможностей.

1. Сопоставь `quality/ACCEPTANCE.md` с тестами и работающим UI.
2. Запусти все Docker-проверки.
3. Собери production image и проверь nginx smoke.
4. Проверь dependency list, лицензии и бюджет ассетов.
5. Проверь запрещённые импорты и отсутствие игрового баланса в коде.
6. Пройди три ключевых E2E: победа, recovery→спасение, поражение.
7. Обнови README/CODEMAP только фактическим состоянием.
8. Составь отчёт с доказательствами и оставшимися реальными рисками.

Не обновляй версии пакетов, не меняй дизайн и не начинай следующую фазу проекта.
