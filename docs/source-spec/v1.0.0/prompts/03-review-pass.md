# Промпт: независимое ревью diff

Не добавляй функции. Сначала только проанализируй текущий diff как строгий ревьюер.

Ищи по приоритету:

1. нарушение спецификации;
2. недетерминированность и ошибки времени;
3. нарушение границ модулей;
4. коэффициенты/тексты в коде;
5. непротестированные границы;
6. лишнюю зависимость или абстракцию;
7. изменение вне текущей задачи;
8. ошибки UX и доступности.

Для каждого finding укажи файл, требование, влияние и минимальное исправление. Не придумывай замечания ради количества. После списка исправь только подтверждённые дефекты и повтори целевые тесты.
