# Промпт: аудит спецификации перед кодом

Проведи аудит текущей задачи без внесения изменений.

1. Сопоставь task, feature-spec, контракты и решения.
2. Выпиши требования в форме `ID → наблюдаемое поведение → проверка`.
3. Найди только реальные противоречия и незакрытые обязательные случаи.
4. Для мелкого пробела предложи минимальное допущение без новой функции.
5. Покажи файлы, которые нужно изменить, и файлы, которые запрещено трогать.
6. Верни план максимум из 8 пунктов.

Не пересказывай весь проект и не предлагай улучшения вне scope.
