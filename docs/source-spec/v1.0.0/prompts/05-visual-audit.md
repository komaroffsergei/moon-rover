# Промпт: визуальный аудит

Сверь UI с `specs/ui/` и соответствующими изображениями из `references/`.

Приоритет текста выше изображения. Изображения задают композицию и характер, но не игровые числа и не функции.

Проверь:

- карта занимает основное пространство;
- панели компактны и не перекрывают карту;
- выбранный объект и допустимые действия очевидны;
- три ресурса центра читаются над объектом и в панели;
- опасные зоны крупные, перекрывают часть прямых путей и имеют безопасные обходы;
- ручной маршрут читается по клеткам;
- recovery window и авария заметны не только цветом;
- 1280×720 не требует горизонтального scroll.

Исправляй только явные расхождения. Не копируй текст, валюту, длительность и автопути с референсов.
