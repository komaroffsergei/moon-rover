# Чек-лист ревью

## Поведение

- [ ] Изменение соответствует только текущей задаче.
- [ ] Все критерии имеют проверяемое доказательство.
- [ ] Пограничные состояния обработаны явно.
- [ ] Пауза и игровые минуты не зависят от wall-clock timers.
- [ ] Один seed воспроизводит результат.

## Архитектура

- [ ] `simulation` не импортирует Phaser, React, Zustand, DOM.
- [ ] Phaser и React не мутируют сущности напрямую.
- [ ] Контент валидируется до создания игрового состояния.
- [ ] Карты, баланс, события, рация и тема разделены.
- [ ] Модуль имеет одну понятную ответственность.

## Простота

- [ ] Нет автоматического поиска маршрута.
- [ ] Нет ненужных `Manager/Service/Factory/Provider`.
- [ ] Нет абстракции с одним применением.
- [ ] Нет дублирующей библиотеки или собственного аналога разрешённой зависимости.
- [ ] Нет кода для будущих функций.

## UI

- [ ] Карта остаётся основным полем.
- [ ] Действия доступны без цепочки модальных окон.
- [ ] Риск/критичность обозначены не только цветом.
- [ ] Текст читается на 1280×720.
- [ ] Ошибочная клетка объясняет отказ.

## Контент и лицензии

- [ ] JSON/Tiled проходит валидатор.
- [ ] Ассеты локальны и перечислены в `THIRD_PARTY_NOTICES.md`.
- [ ] Нет runtime CDN и платной зависимости.
- [ ] Размеры изображений/аудио укладываются в бюджет.

## Docker

- [ ] Все команды воспроизводятся с чистого checkout.
- [ ] Production image не содержит dev dependencies.
- [ ] Playwright package и image одной версии.
- [ ] Нет секретов и локальных путей в образе.
