# Приёмка продукта

## Запуск

- [ ] Новый разработчик запускает игру командой `docker compose up app`.
- [ ] Production image собирается и отдаёт SPA через nginx.
- [ ] Игра не требует backend, БД, ключей и внешнего API.

## Карты

- [ ] Доступны 4 выбираемые карты.
- [ ] Каждая карта хранится в Tiled JSON и метаданных уровня.
- [ ] Препятствия непроходимы.
- [ ] Большие danger zones местами перекрывают прямые направления к центрам.
- [ ] Есть короткие рискованные и заметно более длинные безопасные обходы; конфигурации различаются между центрами.
- [ ] Игрок вручную кликает маршрут по соседним клеткам.

## Центры

- [ ] Видны кислород, пайки и оборудование.
- [ ] Кислород/пайки расходуются по контентным коэффициентам.
- [ ] Потребность в оборудовании возникает дискретно.
- [ ] Пороговые сообщения 50/25/10/5/1% появляются один раз.
- [ ] При 0 включается окно 30 игровых минут с сообщениями.
- [ ] Доставка до истечения окна возвращает центр в работу.
- [ ] Истечение окна завершает смену поражением.

## Роверы

- [ ] Курьер имеет батарею, скорость и общую грузоподъёмность.
- [ ] Можно загрузить смесь ресурсов.
- [ ] Заряд восстанавливается только на базе.
- [ ] Ремонтная бригада не доставляет груз.
- [ ] Метеорит, буря и кратер соответствуют спецификации.
- [ ] Ремонт/спасение выполняются через соседство.
- [ ] Батарея передаётся ремонтной бригаде полностью и только после подтверждения.

## Исход

- [ ] Смена длится 8 реальных минут = 8 игровых часов.
- [ ] Пауза останавливает симуляцию.
- [ ] Победа: по окончании смены все центры работают.
- [ ] Возврат роверов на базу не является условием победы.

## Интерфейс

- [ ] Карта доминирует, панели компактны по бокам.
- [ ] Над центрами видны три progress bar.
- [ ] Выбранный объект показывает свойства и допустимые действия.
- [ ] Рация является игровым журналом, а не чатом.
- [ ] Есть выбор уровня, briefing, gameplay, route mode, recovery, rescue, pause, victory, defeat.
- [ ] Интерфейс пригоден для desktop 1280×720 и выше.

## Качество

- [ ] SimulationEngine — единственный источник истины.
- [ ] Случайность детерминирована seed.
- [ ] Нет MapLibre, A*, backend, ECS, DI, CQRS и процедурной генерации.
- [ ] Все обязательные Docker-команды проходят.
