# Definition of Done

Функция считается готовой только когда:

- [ ] требования feature-spec реализованы, а `Не входит` не нарушено;
- [ ] добавлены минимальные тесты на happy path, границу и отказ;
- [ ] все затронутые JSON/Tiled валидируются;
- [ ] lint, format, typecheck и целевые тесты проходят в Docker;
- [ ] нет ошибок браузерной консоли в затронутом сценарии;
- [ ] код прошёл три прохода ревью;
- [ ] добавленная зависимость утверждена и документирована;
- [ ] документация и CODEMAP обновлены, если изменилась структура/поведение;
- [ ] создан отчёт задачи с фактическими командами;
- [ ] diff не содержит незапрошенной функции, временного debug-кода или TODO.

Для T012 дополнительно проходят полный E2E, production build и запуск nginx-контейнера.
