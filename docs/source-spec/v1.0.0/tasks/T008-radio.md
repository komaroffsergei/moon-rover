# T008. Рация и журнал событий

**Feature spec:** `features/F008-radio.md`  
**Зависит от:** T007

## Цель

Преобразовывать доменные события в понятные, недублирующиеся сообщения рации.

## Контекст задачи

Открыть только перечисленные файлы и уже созданный код, непосредственно связанный с задачей:

- `features/F008-radio.md`
- `specs/gameplay/08-radio.md`
- `specs/gameplay/03-centers-resources.md`
- `specs/gameplay/06-hazards-events.md`
- `contracts/radio.schema.json`
- `contracts/examples/radio.ru.json`

Не читать весь пакет «на всякий случай». Если нужное правило отсутствует, применить порядок приоритетов из `README.md`.

## В scope

- шаблоны сообщений по eventCode;
- пороговые сообщения 50/25/10/5/1%;
- сообщения recovery 30/20/10/5/1 мин;
- происшествия и спасение;
- приоритет и ограниченный журнал;
- ссылка на objectId/cell;

## Ожидаемые результаты

- `src/simulation/radio/*`;
- `src/content/radio/*`;
- `unit-тесты форматирования и дедупликации`;

Конкретные имена внутренних файлов можно скорректировать, если сохраняются границы ответственности и это объяснено в отчёте.

## Критерии приёмки

- [ ] один доменный event создаёт максимум одно сообщение;
- [ ] все шаблоны проходят schema validation;
- [ ] сообщение сохраняет objectId и уровень важности;
- [ ] цензурный шум на 1% хранится как шаблон, не в коде;
- [ ] рация не является пользовательским чатом;

## Не входит

- DOM-компонент рации;
- голосовая озвучка;
- сетевой канал;

## Обязательный рабочий цикл

1. До изменений записать план максимум из 8 пунктов.
2. Найти самый маленький законченный вертикальный срез задачи.
3. Сначала добавить/уточнить проверяемые тесты или валидаторы требования.
4. Реализовать минимальный код, необходимый для прохождения этих проверок.
5. Запустить команды через Docker из `quality/THREE_PASS_WORKFLOW.md`.
6. Просмотреть итоговый diff и удалить код, не нужный этой задаче.
7. Создать `reports/T008.md` по `quality/REPORT_TEMPLATE.md`.

## Запрет завершения

Задача не считается выполненной по фразе «должно работать». В отчёте нужны фактические команды, их результат и ссылки на тесты, доказывающие каждый критерий.
