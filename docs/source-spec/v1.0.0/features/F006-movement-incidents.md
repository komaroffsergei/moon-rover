# F006. Движение и происшествия

## Цель

Продвигать роверы и детерминированно применять три события.

## Требования

- логический переход отделён от визуальной интерполяции;
- списание батареи при входе;
- pure-rand seed;
- normal/hazard chance и cooldown;
- буря, метеорит, кратер;

## Не входит

- Спасательные операции;

## Приёмка

Одинаковый seed воспроизводит события; покрыты все переходы состояний.
