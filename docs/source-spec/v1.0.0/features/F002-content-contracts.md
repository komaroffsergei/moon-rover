# F002. Контент и валидация

## Цель

Создать загрузку level meta, balance, incidents, radio, theme и Tiled-контракта.

## Требования

- Zod-схемы соответствуют contracts;
- ошибки содержат путь и стабильный код;
- валидатор слоёв, объектов, ID, достижимости и risk-choice;
- валидный пример и невалидные fixtures;

## Не входит

- Phaser rendering и четыре финальные карты;

## Приёмка

Валидный набор загружается; каждое критичное нарушение ловится тестом.
