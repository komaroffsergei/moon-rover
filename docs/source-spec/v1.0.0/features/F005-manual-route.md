# F005. Ручной маршрут

## Цель

Реализовать маршрут клетка за клеткой без A*.

## Требования

- 4-соседство и walkable;
- undo/clear/confirm;
- допустимые цели;
- прогноз времени, батареи, риска;
- перенаправление исправного ровера;

## Не входит

- Автоматический поиск пути;

## Приёмка

Unit-тесты геометрии и E2E кликов по клеткам проходят.
