# F008. Рация

## Цель

Преобразовывать domain events в локализованные сообщения.

## Требования

- шаблоны JSON;
- категории/severity;
- история 100;
- dedupe threshold;
- клик выделяет источник, поля ввода нет;

## Не входит

- Голос и генеративные реплики;

## Приёмка

Тесты шаблонов/дедупликации и E2E перехода к объекту.
