# F011. Четыре карты

## Цель

Создать четыре разные валидные карты.

## Требования

- состав по balance spec;
- крупные связные hazards;
- короткие рискованные и длинные безопасные пути;
- локальные фоны/themes;
- risk validator и smoke runs;

## Не входит

- Процедурная генерация;

## Приёмка

Все карты выбираются и проходят ускоренную смену без исключений.
