# F010. React UI

## Цель

Собрать компактные экраны и панели.

## Требования

- level select, briefing, game, pause, victory, defeat;
- tabs centers/rovers;
- selected object + radio;
- critical/recovery/rescue modes;
- plain CSS, keyboard, reduced motion;

## Не входит

- UI framework и router;

## Приёмка

E2E основных сценариев на 1280×720 и 1920×1080.
