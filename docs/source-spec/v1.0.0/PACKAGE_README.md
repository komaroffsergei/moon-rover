# Moon Courier Crisis — SDD-пакет для Codex

Это нормативный комплект спецификаций и референсов для последовательной разработки браузерной игры. Исходного кода здесь нет: Codex должен создавать его по одной задаче, не расширяя scope и не придумывая инфраструктуру, о которой никто не просил.

## Быстрый старт

1. Распаковать пакет в корень нового Git-репозитория.
2. Передать Codex содержимое `CODEX_START.md`.
3. Открыть `TASK_INDEX.md`, затем выполнять задачи по `tasks/manifest.json` строго по одной за рабочий цикл.
4. После каждой задачи создавать отчёт по `quality/REPORT_TEMPLATE.md`.
5. Все команды разработки и проверки запускать через Docker Compose.

## Приоритет требований

При противоречии действует порядок:

1. `specs/product/03-decisions.md`;
2. соответствующая `features/Fxxx-*.md`;
3. JSON-контракты из `contracts/`;
4. остальные спецификации;
5. задачи;
6. изображения.

Изображения задают композицию, но не числа. Запрещено копировать с них случайную длительность смены, конечные запасы базы, автомаршруты, валюту, чат или обязательный возврат роверов.

## Стек

- Node.js 24 LTS, pnpm 11, TypeScript strict;
- Vite 8;
- Phaser 4.2.x;
- Tiled 1.12.x JSON;
- React 19.2.x + Zustand 5.x;
- Zod 4.x;
- pure-rand;
- Vitest 4.x + Playwright;
- ESLint flat config + Prettier;
- Docker multi-stage + nginx.

## Архитектура

`SimulationEngine` — единственный источник истины. Phaser только рисует карту и переводит клики в команды. React только показывает боковые панели и отправляет команды. Карты, баланс, события, рация и темы находятся отдельно.

## Каталоги

- `AGENTS.md`, `.agents/skills/` — постоянные правила Codex;
- `specs/` — продукт, геймплей, UI, техника;
- `features/` — законченные feature-spec;
- `contracts/` — схемы и примеры JSON/Tiled;
- `tasks/` — 12 последовательных этапов, schema и правила статусов;
- `quality/` — тесты, ревью, DoD, бюджет контекста и правила закрытия пробелов;
- `prompts/` — заполненные промпты;
- `docker/` — шаблоны контейнеров и точные команды;
- `references/` — исследование и изображения.

## Не входит

Backend, БД, авторизация, WebSocket, мультиплеер, SSR, MapLibre, физика, ECS, DI, CQRS, процедурная генерация, редактор внутри игры, экономика, прокачка и облачное сохранение.


## Рекомендуемый цикл Codex

Подробно: `quality/CONTEXT_BUDGET.md` и `quality/GAP_HANDLING.md`.

- один task = один сеанс;
- план → минимальная реализация → spec review → simplicity review → regression;
- следующий сеанс читает новый task prompt и короткий отчёт предыдущей задачи;
- изображения открываются только в UI/map-задачах;
- весь пакет не загружается в контекст одновременно.
