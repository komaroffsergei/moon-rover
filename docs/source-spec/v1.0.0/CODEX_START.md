# Стартовая команда для Codex

Передай Codex следующий текст из корня репозитория:

> Активируй `$moon-courier-sdd` и прочитай `AGENTS.md`. Проверь `tasks/manifest.json`, возьми только первую pending-задачу с выполненными зависимостями и выполни её по готовому промпту `prompts/tasks/Txxx.md`. До кода проведи spec-audit и составь план максимум из 8 пунктов. Все команды выполняй через Docker Compose. После реализации выполни три прохода `quality/THREE_PASS_WORKFLOW.md`, создай `reports/Txxx.md` и остановись, не начиная следующую задачу.

## Рекомендуемый режим

- Для T001–T002 и T009–T012: высокий reasoning/Plan mode.
- Для изолированных T003–T008 после spec-audit: medium/high.
- Один новый сеанс на задачу. В следующий сеанс передавать только отчёт предыдущей задачи и новый task prompt.

## Не передавать каждый раз

Не вставляй вручную весь пакет в prompt. `AGENTS.md`, skill и task routing уже делают это. Повторение спецификаций расходует контекст и повышает шанс противоречий, что довольно традиционный способ превратить хорошую инструкцию в шум.
