# Ручной маршрут

Автоматического поиска пути в игре нет.

## Допустимый шаг

Клетка внутри карты, `walkable=true`, Манхэттен-расстояние от конца маршрута равно 1. Другой ровер не блокирует клетку.

## Управление

- клик — добавить шаг;
- клик по предыдущей / Esc / «Отменить шаг» — удалить конец;
- «Очистить» — удалить черновик;
- «Подтвердить» — сохранить;
- «Отправить» — применить задачу.

Кандидатные клетки подсвечиваются. Панель показывает длину, время, батарею и оценочный риск:

```text
risk = 1 - product(1 - effectiveCellChance)
```

Маршрут заканчивается на базе, центре, клетке ровера или соседней клетке спасения. Новый маршрут исправного ровера начинается от текущей клетки.
