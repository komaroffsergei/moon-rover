# Роверы, груз и батарея

## Архетипы

| Тип | Груз | Батарея | Минут на обычную клетку |
|---|---:|---:|---:|
| Быстрый | 40 | 90 | 1.5 |
| Стандартный | 60 | 100 | 2.0 |
| Тяжёлый | 90 | 120 | 2.5 |
| Ремонтный | 0 | 100 | 2.0 |

## Батарея

```text
cost = terrain.movementCost × rover.batteryCostMultiplier
```

Стоимость списывается при входе. Вес груза расход не меняет. UI показывает прогноз. Отправка с недостаточным прогнозом допускается с предупреждением. Зарядка только на базе.

## Груз

Кислород, пайки и оборудование смешиваются в общей вместимости. База не имеет лимита. Загрузка и разгрузка мгновенные. Ремонтный ровер не загружается.
