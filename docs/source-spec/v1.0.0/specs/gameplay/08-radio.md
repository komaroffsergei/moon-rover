# Рация

Рация — игровой журнал в форме сообщений от центров и роверов.

## Правила

- новые сообщения сверху, максимум 100;
- клик выделяет источник и центрирует карту;
- фильтры: все, центры, роверы, аварии;
- поля ввода нет;
- категории `INFO/WARNING/CRITICAL/EVENT/RESCUE/SYSTEM`;
- шаблон до 180 символов;
- важная информация понятна без шутки, ирония допустима второй фразой;
- тексты лежат в JSON и не генерируются моделью во время игры;
- пороговые сообщения дедуплицируются.
