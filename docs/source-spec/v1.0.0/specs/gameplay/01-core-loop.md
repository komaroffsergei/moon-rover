# Основной цикл

## Перед сменой

Игрок выбирает карту, видит длительность, количество центров/роверов, риск и особенность, затем открывает брифинг.

## Во время смены

- следит за ресурсами и прогнозами;
- выбирает ровер и смешанный груз;
- вручную строит маршрут;
- сравнивает время, батарею и оценочный риск;
- перенаправляет исправный ровер;
- реагирует на аварии;
- восстанавливает центр до истечения recovery.

## Конец

На 480-й секунде все центры должны быть `WORKING` или `WARNING`. `RECOVERY/LOST` означает поражение. Положение роверов не учитывается.
