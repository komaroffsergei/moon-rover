# Доступность

- основные действия доступны мышью и клавиатурой;
- Esc отменяет черновик/закрывает контекстное окно;
- Space ставит паузу, если фокус не в контроле;
- цвет дополняется иконкой, текстом и рамкой;
- кнопка минимум 36 px высотой, текст минимум 14 px;
- zoom колёсом, pan средней кнопкой или Space+drag;
- видимый focus;
- критические события не зависят от звука;
- `prefers-reduced-motion` отключает пульсацию и лишние переходы.
