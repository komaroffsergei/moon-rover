# Компоновка игрового экрана

## Размеры при 1920×1080

- top bar 56–64 px;
- левая панель 250–300 px;
- правая 300–340 px;
- нижняя 44–56 px;
- остальное занимает карта.

## Top bar

Название уровня, время/остаток, краткая цель, пауза. Глобальные запасы базы не показывать: они не ограничены.

## Слева

Переключатель `Центры / Роверы`. Центр: три полосы и прогноз. Ровер: батарея, груз, статус и задача. Не показывать одновременно два длинных списка.

## Справа

Свойства выбранного объекта и только допустимые сейчас действия. Ниже — компактная рация и переход к журналу.

## Карта

Сетка слабее объектов. Опасные зоны крупные, полупрозрачные и штрихованные. Препятствия читаемы. Маршрут контрастный. Над центром три полосы без лишнего текста; точные проценты в панели.
