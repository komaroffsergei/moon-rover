# Карта экранов

## Отдельные экраны

1. Выбор уровня — четыре карты, крупный preview, параметры.
2. Брифинг — цель, состав, риски, запуск.
3. Игровой экран — карта и боковые панели.
4. Пауза — компактное модальное окно поверх игры.
5. Победа — метрики, следующий уровень/повтор.
6. Поражение — причина, цепочка событий, повтор/выбор карты.

## Режимы игрового экрана

Обзор, загрузка, построение маршрута, критический центр, авария, ремонт и передача батареи не являются отдельными страницами. Меняется правая панель и подсветка карты; сама карта остаётся на месте.
