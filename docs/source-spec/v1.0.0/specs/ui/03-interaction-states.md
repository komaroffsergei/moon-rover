# Состояния взаимодействия

## Центр

Ресурсы, прогноз до нуля, статус/recovery timer, входящие доставки, «Выбрать ровер».

## Курьер на базе

Батарея, скорость, вместимость, редактор смешанного груза, «Маршрут».

## Курьер в пути

Маршрут/прогресс, прогноз батареи, груз, «Перестроить маршрут». «На базу» лишь переключает режим ручного маршрута к базе.

## Построение маршрута

Подсветить соседние допустимые клетки; показать длину, время, батарею, риск; действия undo, clear, confirm, dispatch. Ресурсы центров остаются видны.

## Критический центр

Красная рамка и `00:30` над центром и в панели. Модалка карту не блокирует. Быстрые действия: выбрать ровер, начать маршрут, показать центр.

## Авария

Маркер типа происшествия, требуемая помощь и выбор спасателя. Передача батареи требует подтверждения с итоговыми зарядами.
