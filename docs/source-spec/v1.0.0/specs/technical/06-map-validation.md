# Валидация карт

## Структура

Проверить слои/типы, embedded tileset, одинаковые размеры, свойства тайлов, одну базу/ремонтный spawn, уникальность ID, ссылки meta и отсутствие объектов на blocked.

## BFS

Валидатор, но не runtime игра, использует короткий BFS:

- каждый центр и spawn достижим от базы;
- нет случайных изолированных островов.

## Выбор риска

Для `riskChoiceCenters`:

1. найти кратчайший путь с опасными клетками;
2. найти путь с запретом опасных;
3. короткий путь обязан пересекать hazard;
4. безопасный существует;
5. его длина в 1.4–1.9 раза больше.

## Зоны

Связность по четырём соседям; обычная крупная зона 8–30 клеток; минимум одна зона на уровнях 2–4 имеет 20+ клеток. Россыпь одиночных красных точек не считается дизайном риска.
