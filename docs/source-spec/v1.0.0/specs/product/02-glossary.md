# Глоссарий

- **Реальная секунда** — секунда пользователя.
- **Игровая минута** — одна реальная секунда.
- **Игровой час** — 60 реальных секунд.
- **Смена** — 480 реальных секунд / 8 игровых часов.
- **Клетка** — элемент ортогональной сетки Tiled.
- **Опасная зона** — связная область повышенного риска.
- **Препятствие** — непроходимая клетка.
- **Центр** — объект с кислородом, пайками и оборудованием.
- **Окно восстановления** — 30 игровых минут после ресурса 0.
- **Курьер** — ровер с грузом.
- **Ремонтная бригада** — ровер без доставки, ремонтирующий другие.
- **Маршрут** — вручную выбранная последовательность соседних клеток.
- **Снимок** — readonly-состояние симуляции для UI/рендера.
- **Команда** — проверяемое намерение игрока.
- **Доменное событие** — произошедший факт для UI и рации.
