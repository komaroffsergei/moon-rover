# Execution plan template

Использовать для каждой задачи T001–T012. План хранится в отчёте задачи, отдельный вечный backlog не создаётся.

## Цель

Одно предложение, совпадающее с задачей.

## Контекст

Перечень файлов из раздела «Контекст задачи». Не добавлять весь репозиторий.

## План (не более 8 шагов)

1. Проверяемый шаг.
2. …

## Файлы

- создать;
- изменить;
- не трогать.

## Риски

Только 1–3 риска, которые могут сорвать критерии приёмки.

## Проверки

Точные Docker-команды и ожидаемые доказательства.

## Стоп-условие

Остановиться после выполнения критериев текущей задачи; следующую feature не начинать.
